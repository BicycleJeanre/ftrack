# Keyboard Shortcuts

Use `Ctrl` on Windows and Linux. On macOS, the application also accepts `Command` for shortcuts shown with `Ctrl`.

## Application shortcuts

- **Focus Scenarios:** `Ctrl+1`
- **Focus Accounts:** `Ctrl+2`
- **Focus Plan & Actuals:** `Ctrl+3`
- **Focus Projections:** `Ctrl+4`
- **Show shortcut help:** `?`

Focus shortcuts do not interrupt normal typing in a text field. Shortcut help
remains available while an input is focused.

## Plan and grid navigation

- **Move between cells:** Arrow keys
- **Move to the next cell:** `Tab`
- **Move to the previous cell:** `Shift+Tab`
- **Edit a cell or save and move down:** `Enter`
- **Cancel a cell edit:** `Esc`
- **Scroll one grid page:** `Page Up` or `Page Down`
- **Jump to the first or last row:** `Home` or `End`
- **Copy the selected cell:** `Ctrl+C`
